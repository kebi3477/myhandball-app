# 계산 규칙 (rules)

전체 원본은 `spec/logic.js`. 랭킹 유저와 대진은 목업이에요(`TODO(v3)`, 서버 집계로 교체 예정).

## 승부예측 — 내 기록
- decided = 결과가 나온 예측(hit ≠ null)
- 적중률 = round(적중 수 / decided × 100)%. decided가 0이면 `-`
- 참여 수(count) = 결과 대기 중인 예측까지 포함한 전체 예측 수

## 승부예측 랭킹
- 랭킹 대상(qualified): 목업 유저 + 나. 나는 **프로필이 있고 확정 경기 10개 이상**일 때만 포함돼요.
  - 목업 유저는 모두 확정 경기가 10개 이상이에요.
- 정렬: 적중률(h/n) 내림차순 → 동률이면 확정 경기 수(n) 내림차순. 그래도 같으면 기존 순서를 유지하고, 같은 순위를 주지 않아요.
- 순위 = 정렬 후 인덱스 + 1. 1~3위는 순위 숫자 색이 #0068FF
- 범위 탭: '전체' 또는 '내 팀 팬'. 내 팀은 프로필 팀, 프로필이 없으면 MY팀이에요.
- rankSub의 상위 % = max(1, ceil(내 순위 / 전체 인원 × 100)). 항상 '전체' 기준으로 계산해요.

## 팬덤 적중률
- 대상 팀: 내 팀이 속한 리그(남자부/여자부)의 팀들
- 팀 적중률 = 그 팀 팬들의 적중 합 / 확정 경기 합. 사용자 평균이 아니라 경기 수 가중 평균이에요.
- 분모에는 랭킹 대상 유저만 들어가요(확정 10경기 이상).
- 적중률 내림차순. 막대 너비 = 적중률 / 1위 적중률 × 100%

## 직관 승률 / 팀 시즌 승률
- **무승부는 두 승률 모두 분모에 들어가요.**
  - 직관 승률 = round(승 / (승+무+패) × 100). MY팀이 뛴 직관 경기만 세요. 0경기면 null, 화면에는 `-`
  - 팀 시즌 승률 = round(승 / (승+무+패) × 100). 0경기면 0
- diff = 직관 승률 - 팀 시즌 승률 (%p)
- MY팀이 뛰지 않은 직관 경기는 '관람'이라 승률 계산에서 빠져요.
- 기록을 저장할 때 응원팀(cheer)도 함께 저장돼요. 기록 당시 MY팀이 그 경기 팀 중 하나면 MY팀, 아니면 null(관람)이에요. 그래서 MY팀이 바뀌어도 기존 기록은 유지돼요.

⚠ 정정: 앞서 드린 배지 프롬프트에 '승리 요정은 무승부 제외'라고 적었는데 틀렸어요. 실제 기준은 **승+무+패 ≥ 3경기이고 diff > 0**이에요.

- 비시즌이면:
  - 일정·캘린더·예측 대진·홈 다음 경기가 모두 빈 목록
  - live 상태인 경기는 final로 취급
  - 다음 경기 D-day 문구: `비시즌 · 개막 D-53`
  - 승부예측 seasonLabel: `25-26 시즌 최종`

## 경기 상태 (pre / live / final)
- 시안에서는 코드상 이름이 `finished`가 아니라 `final`이에요.
- 상태는 데이터에 들어 있는 값을 써요. 일정 목업은 칩 라벨로 매핑돼요:
  - `LIVE` → live
  - `경기종료` → final
  - 시각(예: `19:00`) → pre
- 실제 앱에서는 서버의 경기 상태 필드를 그대로 쓰면 돼요.
- 상태별 동작:
  - 경기 상세 기본 탭: pre면 '예측', 그 외엔 '중계'
  - 진행 분: live면 raw.minute(없으면 42), final이면 60, pre면 0
- 칩:
  - 홈: live `LIVE` #FF3B30 / final `경기 종료` #808080 / pre `경기 예정` #0068FF
  - 팀 캘린더: live `LIVE` / final `경기 종료` / pre `D-n`
- 직관 기록: live 경기를 기록하면 final로 저장돼요.

## 예측 마감
- 경기 상세에서 status가 pre일 때만 예측할 수 있어요.
- 예측 목록의 경기는 closed(마감) 또는 picked(선택함)면 '예측 가능' 수에서 빠져요.
