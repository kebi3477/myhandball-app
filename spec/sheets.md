# 프로필 시트 · 직관 기록 추가 시트

마크업 원문은 `spec/sheets.html`, 로직은 `spec/logic.js`(`openProfile`, `saveProfile`, `leaveRanking`, `nickCheck`)에 있어요.

## 프로필 시트 (`pf.open`)
여는 곳:
- 승부예측 탭의 [시작하기]
- 프로필 없이 예측을 고를 때(고른 예측은 `pfPending`에 보관)
- MY/승부예측 프로필 카드 편집

모양: 바텀시트, 배경 딤 rgba(0,0,0,0.5), radius 24 24 0 0, 최대 높이 92%, 패딩 12/24/28, 요소 간격 20.

위에서 아래 순서:
1. 핸들: 40×4, c.border
2. 제목(20/800): 처음이면 `승부예측 프로필 만들기`, 수정이면 `프로필 편집`
   - 부제(13, c.textSub): `랭킹에서 나를 구분할 닉네임과 응원팀만 있으면 돼요`
3. 닉네임
   - 라벨 `닉네임`, 오른쪽에 `n/10`
   - 입력칸: 50px, c.card, radius 14, placeholder `2~10자 · 한글, 영문, 숫자`, 오른쪽에 [추천] 버튼
   - 테두리: 비었으면 없음, 사용 가능하면 #0068FF, 불가면 #E5484D
   - 아래 메시지(12): `nickCheck`가 돌려주는 문구. 사용 가능이면 #0068FF, 불가면 #E5484D
     - `2자 이상 입력해 주세요`
     - `한글·영문·숫자·_만 쓸 수 있어요 (공백·자음 단독 불가)`
     - `사용할 수 없는 단어가 들어 있어요`
     - `이미 사용 중인 닉네임이에요`
     - `사용할 수 있는 닉네임이에요`
4. 응원팀
   - 라벨 `응원팀`, 오른쪽 `MY 팀과 함께 바뀌어요`
   - [남자부]/[여자부] 필 + 4열 팀 그리드. 선택한 팀은 테두리 #0068FF, 배경 rgba(0,104,255,0.1)
5. 공개 범위 카드 (c.card, radius 16) — 2열 표

   | 항목 | 내용 |
   |---|---|
   | `공개` | `닉네임 · 응원팀 · 예측 적중 기록` |
   | `받지 않음` | `이름 · 이메일 · 전화번호 · 위치` |
   | `구분 방법` | `기기마다 익명 ID가 자동 생성돼요` |

   - 아래에 밑줄 링크 `개인정보 처리방침`
6. **동의 체크박스 (pfConsent)**: 22×22, radius 6
   - 문구: `랭킹에 닉네임·응원팀 공개에 동의해요` + `(필수)`(c.textSub)
   - 처음 만들 때는 체크 해제 상태, 수정할 때는 체크된 상태로 시작
7. 기본 버튼: 52px, radius 26
   - 문구: 처음이면 `랭킹 참여하기`, 수정이면 `저장`
   - 활성 조건: 닉네임 OK AND 동의 AND 팀 선택. 활성 #0068FF / 비활성 #9a9a9a
8. 보조 버튼(13, c.textSub): 예측을 보관 중이면 `나중에 하고 예측만 저장할게요`, 아니면 `닫기`
9. **수정 모드에서만** 맨 아래(12, #E5484D): `랭킹 참여 중단 · 프로필 삭제`
   - 누르면 바로 `leaveRanking`을 실행하고 토스트 `랭킹 참여를 중단했어요. 예측 기록은 기기에 남아요`
   - 시안에는 확인 단계가 없어요. 앱에서는 확인 다이얼로그를 넣는 걸 권장해요.

**처음과 수정의 차이**: 제목, 동의 초기값, 저장 문구, 참여 중단 링크 네 가지만 달라요.

## 직관 기록 추가 시트 (`attSheetOpen`)
모양: 바텀시트, 최대 높이 85%, 패딩 12/24/24, 간격 16.
- 제목(20/800): `다녀온 경기를 골라주세요`
- 부제(13): `25-26 시즌 {MY팀} 경기 · {n}경기 선택됨`
- 경기 행 목록(스크롤)
  - 행: radius 16, 패딩 12/14, 둥근 체크 22px, 경기명(14/700), `{날짜} · {경기장}`(11), 오른쪽 점수(Impact 16)
  - 선택 시: 배경 rgba(0,104,255,0.1), 테두리 1.5 #0068FF, 체크 #0068FF
  - 미선택: 배경 c.card, 체크 테두리 c.textFaint
- 탭하면 즉시 저장·해제(토글). 확인 단계 없음
- 하단 [완료]: 52px, #0068FF, 누르면 닫기만 해요.
