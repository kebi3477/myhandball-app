# 스크립트가 만드는 문구 (copy)

원문 그대로. `${}`는 변수 치환. 전체 원본은 `spec/logic.js`.

## 에러 상태 — errTitle / errDesc / errIconPath
조건: `demoState`가 '오프라인' 또는 '서버 오류'이고, 사용자가 닫지 않았을 때(`!errDismissed`) → `hasError`.

| 상태 | errTitle | errDesc (\n = 줄바꿈) | errIconPath (24×24, stroke) |
|---|---|---|---|
| 오프라인 | 인터넷에 연결되어 있지 않아요 | Wi-Fi나 모바일 데이터 연결을 확인한 뒤\n다시 시도해 주세요. | `M2 8.5a15 15 0 0 1 20 0M5.5 12a10 10 0 0 1 13 0M9 15.5a5 5 0 0 1 6 0M12 19h.01M3 3l18 18` |
| 서버 오류 | 정보를 불러오지 못했어요 | 일시적인 오류가 발생했어요.\n잠시 후 다시 시도해 주세요. | `M12 8v5M12 16.5h.01M10.3 3.9L2.4 17.6A2 2 0 0 0 4.1 20.6h15.8a2 2 0 0 0 1.7-3L13.7 3.9a2 2 0 0 0-3.4 0z` |

- 게임 상세 에러 본문은 errDesc가 아니라 마크업에 고정된 문구: "문자중계·기록·예측·MVP 투표는\n연결이 복구되면 다시 볼 수 있어요."
- 빈 상태(경기 없음 등)는 모두 마크업에 적힌 고정 문구예요. 스크립트에서 만들지 않아요.

## 레슨 완료 화면
- doneHeadline: 방금 마지막 레슨을 끝내서 수료했으면 `입문 가이드 수료!`, 아니면 `레슨 완료!`
- doneTitle: `${레슨 title} 레슨을 끝냈어요`
- doneQuiz: 퀴즈를 맞혔으면 `정답`, 틀렸으면 `오답`
- doneNextLabel: 다음 레슨이 남아 있으면 `다음 레슨`, 마지막 레슨이면 `가이드 완료`
- 수료 여부(justGraduated): 이번 완료로 5개를 처음 모두 채운 경우에만 true. 수료일은 `YYYY.MM.DD`

## 가이드 배너
- guideGradLine: 수료일이 있으면 `${YYYY.MM.DD} 수료 · 레슨 다시 보기 ›`, 없으면 `수료 완료 · 레슨 다시 보기 ›`
- guideHeadline: 완료 0개 → `핸드볼, 같이 배워볼까요?` / 5개 모두 → `핸드볼 마스터 달성!` / 그 사이 → `좋아요, 계속 가볼까요?`
- guideDoneCount `n`, guidePct `n/5×100%`

## 승부예측 (pv)
- openLabel: 비시즌이면 `''`(빈 값) / 예측 가능한 경기가 있으면 `${n}경기 예측 가능` / 없으면 `모두 참여했어요`
  - n = 마감되지 않았고 아직 고르지 않은 경기 수
  - openColor: n>0이면 #0068FF, 아니면 textNeutral
- seasonLabel: 비시즌이면 `25-26 시즌 최종`, 아니면 `25-26 시즌 · 매주 월 갱신`
- rankAll: 랭킹에 있으면 `${순위}위`, 없으면 `-`
- rankSub: 랭킹에 있으면 `전체 상위 ${max(1, ceil(순위/전체인원×100))}%`, 없으면 `${10 - 확정경기수}경기 더 참여`
- meHint: 프로필이 없으면 `프로필을 만들면 내 순위가 여기에 표시돼요 ›`(탭하면 프로필 만들기), 확정 10경기 미만이면 `확정 ${n}경기 · ${10-n}경기 더 참여하면 랭킹에 올라요`
  - showMeHint = 프로필 없음 OR 확정 경기 < 10
- 최근 예측 칩: 결과 전 `대기`(#9a9a9a) / 적중 `적중`(#0068FF) / 실패 `실패`(#E5484D)

## 직관 (av)
- cheerLine: `응원 경기 ${승+무+패} · 관람 ${전체 직관 - (승+무+패)}`
  - 승·무·패는 MY팀이 뛴 경기만 셈. MY팀이 없는 경기는 '관람'
- wdl: `${승}-${무}-${패}`
- rate: 직관 승률 `n%`, 응원 경기가 0개면 `-`
- teamRate: `n%`
- stampCount: `${방문한 곳}/${리그 경기장 수} 경기장`
- stampExtra: `+ 다른 리그 경기장 ${n}곳`. n = MY팀 리그 밖 홈팀 경기장의 고유 개수, n>0일 때만 표시

## 토스트 (toastMsg) — 2.4초 표시
| 동작 | 문구 |
|---|---|
| 닉네임 변경 성공 | 닉네임을 바꿨어요 |
| 프로필 저장 (기존 프로필 수정) | 프로필을 저장했어요 |
| 프로필 저장 (처음 만들 때) | ${닉네임}님, 랭킹에 참여했어요 |
| 랭킹 참여 중단 | 랭킹 참여를 중단했어요. 예측 기록은 기기에 남아요 |
| 캘린더 추가 — 예정 경기 없음 | 추가할 예정 경기가 없어요 |
| 캘린더 추가 성공 | 캘린더 파일을 저장했어요 (${n}경기) |
| 오프라인에서 직관 기록 추가 | 기기에 저장했어요. 연결되면 자동으로 동기화돼요. |
| MY팀 변경 (직관 기록이 1개 이상 있을 때) | MY팀이 바뀌어도 이전 직관 기록은 그대로 유지돼요 |
| 네트워크 실패 (오프라인) | 오프라인 상태라 ${what} 못했어요. 연결을 확인해 주세요. |
| 네트워크 실패 (서버 오류) | 일시적인 오류로 ${what} 못했어요. 잠시 후 다시 시도해 주세요. |

네트워크 실패 문구의 `${what}`에 들어가는 값:
- 닉네임 변경 → `닉네임을 바꾸지`
- 프로필 저장 → `프로필을 저장하지`
- 캘린더 추가 → `캘린더에 추가하지`
- 응원글 등록 → `응원글을 등록하지`
