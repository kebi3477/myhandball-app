# 응원글 신고 · 차단

마크업 원문은 `spec/moderation.html`, 로직은 `spec/logic.js`(`submitReport`, `confirmBlock`, `unblock`, `mod` 객체)에 있어요.
서버 연동 지점에는 `TODO(v3)` 주석을 달아 뒀어요.

## (a) 진입점 — 모든 응원글 오른쪽 위 `⋯`
- 위치: 헤더 줄(아바타 · 닉네임 · 날짜) 맨 오른쪽. 터치 영역 32×32, 점 3개 r1.8, c.textSub
- 길게 누르기와 스와이프는 쓰지 않아요.
- 기존에 카드 오른쪽 아래 있던 `삭제` 텍스트는 없앴어요. 이제 내 글도 `⋯`에서 삭제해요.
- 탭하면 액션 시트가 열려요. 바텀시트, 패딩 12/16/24
  - 상단 문구(12, c.textSub): `{닉네임}님의 응원글`
  - **내 글**: `삭제`(#E5484D, 휴지통 아이콘) → 기존 인라인 확인 `이 응원글을 삭제할까요?` [취소] [삭제]
  - **남의 글**:
    - `신고하기`(c.text, 깃발 아이콘)
    - `이 사용자의 글 보지 않기`(#E5484D, 금지 아이콘)
  - 항목 행: 52px, 15/600, 아이콘 20px, 간격 12
  - 맨 아래 [취소]: 48px, radius 24, c.card

## (b) 신고 시트
바텀시트, 최대 높이 92%, 패딩 12/24/24, 간격 18.
- 제목(20/800): `응원글 신고`
- 부제(13, c.textSub): `신고 사유를 골라주세요. 신고한 사람은 상대에게 알려지지 않아요.`
- 대상 글 미리보기: c.card, radius 14. 작성자(12/700) + 본문(13, 최대 2줄)
- 사유 라디오 4개: 52px, radius 14, 테두리 1.5
  - 선택 시: 테두리 #0068FF, 배경 rgba(0,104,255,0.08), 안쪽 점 #0068FF

  | 서버 값 | 화면 문구 |
  |---|---|
  | `spam` | 스팸·광고 |
  | `abuse` | 욕설·비방·혐오 표현 |
  | `sexual` | 음란·선정적인 내용 |
  | `other` | 기타 |
- 상세 입력칸: 최대 200자, 최소 높이 76, 아래에 `n/200`
  - placeholder: 기본 `자세한 내용을 적어주세요 (선택, 최대 200자)`
  - `other`를 고르면 `어떤 문제인지 적어주세요 (필수, 최대 200자)` — 이때는 필수 입력
- 체크박스: `이 사용자의 글도 보지 않기`(기본 해제). 체크하면 신고와 차단을 함께 처리
- [신고하기]: 52px, radius 26
  - 활성 #E5484D / 비활성 c.textFaint
  - 활성 조건: 사유를 골랐고, `other`면 상세 입력도 있음
- 버튼 아래(11, c.textSub): `신고한 글은 바로 숨겨지고, 운영정책에 따라 24시간 안에 검토해요.`
  - '24시간'은 운영팀 확인이 필요해요. Apple은 신고에 적시 대응할 것을 요구해요.

동작:
- 성공 → 시트 닫기, 그 글을 내 화면에서 바로 숨김
  - 토스트: `신고가 접수됐어요. 검토 후 조치할게요`
  - 차단도 체크했으면: `신고하고 이 사용자의 글을 숨겼어요`
- 서버 `409` → 시트 닫기, 토스트 `이미 신고한 응원글이에요`
- 네트워크 실패 → `오프라인 상태라 신고를 접수하지 못했어요. 연결을 확인해 주세요.` / `일시적인 오류로 신고를 접수하지 못했어요. 잠시 후 다시 시도해 주세요.`

## (c) 차단
- 진입 경로 두 가지:
  1. 액션 시트 `이 사용자의 글 보지 않기` → 확인 다이얼로그
  2. 신고 시트의 체크박스 → 다이얼로그 없이 신고와 함께 처리
- 확인 다이얼로그: 가운데 모달, 최대 너비 320, radius 20, 패딩 24/20/16
  - 제목(17/800): `{닉네임}님의 글을 보지 않을까요?`
  - 본문(13, c.textSub): `이 사용자의 응원글이 모든 팀에서 보이지 않아요. 설정 > 차단한 사용자에서 언제든 해제할 수 있어요.`
  - 버튼 2열(46px): [취소](c.card) [보지 않기](#E5484D, 흰 글자)
- 차단 후 토스트: `{닉네임}님의 글을 더 이상 보지 않아요`
- 차단 대상은 사용자 단위예요. 시안은 닉네임으로 매칭하지만, 앱에서는 작성자 uid로 해야 해요.
- 네트워크 실패 시 `{what}`: `차단하지` / `차단을 해제하지`

**차단 목록 화면 — 필요해요.** 설정에 `차단한 사용자` 항목을 추가했어요.
- 설정 그룹: 알림 그룹 아래, 약관 그룹 위에 단독 카드. 오른쪽에 `{n}명 >`
- 화면 제목: `차단한 사용자`
- 안내(12, c.textSub): `차단한 사용자의 응원글은 모든 팀에서 보이지 않아요. 해제하면 다시 보여요.`
- 행: 팀 로고 32 + 닉네임(14/700) + `{YYYY.MM.DD} 차단`(11) + [해제](32px 필, 테두리 c.border)
  - 해제는 확인 없이 바로 처리, 토스트 `{닉네임}님 차단을 해제했어요`
- 비어 있을 때: `차단한 사용자가 없어요` / `응원글의 ⋯ 메뉴에서 차단할 수 있어요`

## (d) 빈 상태 · 숨김 안내 (응원글 탭)
- 보이는 글이 0개이고 숨긴 글이 있을 때:
  - 제목(15/700) `보이는 응원글이 없어요`
  - 본문(12) `차단하거나 신고한 글은 숨겨져 있어요`
  - 링크(12/700, #0068FF) `차단한 사용자 관리 ›` → 차단 목록 화면
- 글이 아예 없을 때: `아직 응원글이 없어요` / `첫 응원을 남겨보세요`
- 보이는 글도 있고 숨긴 글도 있을 때: 목록 아래 가운데(11, c.textSub) `차단·신고로 숨긴 글 {n}개` → 탭하면 차단 목록
- 내 글은 차단이나 신고로 숨겨지지 않아요.
